# 크보력 (KBORYEOK)

KBO 팬을 위한 데일리 야구 아케이드입니다. 오늘의 크보선수와 기록 TOP 10을 찾는 크보텐을 플레이할 수 있습니다.

## 개발

```bash
npm install
npm run dev
```

선수 데이터 갱신과 검수 방법은 [DATA_PIPELINE.md](./DATA_PIPELINE.md)를 참고하세요.
