# 크보력 (KBORYEOK)

매일 한 명의 KBO 선수를 추리하는 야구 퀴즈입니다. 팀, 포지션, 투타 유형, 나이와 등번호 힌트로 정답을 좁혀갑니다.

## 개발

```bash
npm install
npm run dev
```

선수 데이터 갱신과 검수 방법은 [DATA_PIPELINE.md](./DATA_PIPELINE.md)를 참고하세요.
