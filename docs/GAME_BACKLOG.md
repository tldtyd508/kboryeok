# 게임 백로그 및 아이디어 풀

이 문서는 아이디어를 보존하기 위한 풀이다. 순번은 개발 우선순위가 아니며, 실제 일정은 [ROADMAP.md](./ROADMAP.md)를 따른다.

상태 표기: `NOW` 현재 운영 · `NEXT` 우선 검토 · `LATER` 후순위 · `IDEA` 탐색

## 선수 추리

1. **오늘의 크보선수** `NOW` — 팀, 포지션, 투타, 나이와 등번호 피드백으로 선수 추리
2. **경력만 보고 맞히기** `LATER` — 구단 이동 경로와 연도로 선수 추리
3. **등번호 연대기** `NEXT` — 시즌별 등번호 변화로 선수 추리
4. **기록 프로필 맞히기** `NEXT` — 이름을 가린 시즌·통산 기록을 단계적으로 공개
5. **점점 선명해지는 선수** `IDEA` — 얼굴 일부, 타격폼, 투구폼, 세리머니를 순차 공개

## 보류 원칙

- 자유입력 판정에 전체 관계 DB가 필요한 게임은 Phase 3 이후로 미룬다.
- 음원, 영상, 사진이 필요한 게임은 사용 권리를 먼저 해결한다.
- 희귀도 게임은 충분한 실제 응답이 쌓이기 전까지 점수의 의미를 과장하지 않는다.
- 멀티플레이 게임은 싱글플레이 핵심 루프와 운영 체계가 안정된 뒤 개발한다.
