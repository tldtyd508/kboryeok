# 크보 빙고 제품 설계

## 한 줄 정의

매 턴 등장하는 KBO 선수 한 명을 4×4 조건판의 빈칸 하나에만 배치해, 제한된 선수 카드 안에 16칸을 완성하는 데일리 전략 퀴즈다.

축구 Football Bingo의 핵심인 `한 선수는 한 칸에만 사용` 규칙을 가져오되, KBO의 구단 계보·포지션·수상·시대·기록 이력을 조건으로 사용한다.

## 왜 다음 게임인가

- 오늘의 크보선수는 추리, 크보텐은 회상, 5001은 계산이다. 빙고는 자원 배분과 선택이 중심이라 플레이 감각이 겹치지 않는다.
- 같은 선수가 여러 조건에 들어갈수록 고민이 생긴다. 유명 선수도 정답을 바로 주는 카드가 아니라 아껴 써야 할 자원이 된다.
- 한 판의 초록색 4×4 결과판이 공유 이미지로 바로 읽힌다.
- 전체 관계 DB가 없어도 검수된 날짜별 스냅샷으로 먼저 출시할 수 있다.

## MVP 규칙

1. 모든 사용자에게 KST 기준 같은 4×4 조건판과 같은 선수 카드 순서를 제공한다.
2. 화면 상단에 선수 카드 한 장이 공개된다.
3. 사용자는 그 선수가 만족하는 빈칸 하나를 선택하거나 패스한다.
4. 정답이면 해당 칸이 선수 이름으로 고정된다. 오답 또는 패스면 카드는 소모된다.
5. 한 선수는 한 칸에만 사용할 수 있고, 채운 칸은 옮길 수 없다.
6. 36장의 카드가 끝나기 전에 16칸을 모두 채우면 성공한다.
7. 일일 점수는 `완성 여부 → 사용 카드 수 → 오답 수` 순으로 비교한다.

초기판에는 프리 스페이스, 힌트, 되돌리기를 두지 않는다. 규칙을 한 문장으로 설명할 수 있는 상태를 유지한다.

## 조건 구성

한 판에는 같은 종류의 조건이 과반을 넘지 않게 한다.

- 구단: 현재 또는 과거 특정 구단에서 정규시즌 1군 출장
- 포지션: 투수, 포수, 내야수, 외야수 또는 세부 포지션
- 수상: 골든글러브, 정규시즌 MVP, 신인상, 한국시리즈 MVP, 올스타 베스트12
- 시대: 데뷔 연도·활동 시즌 구간
- 기록: 검증하기 쉬운 누적 기준(100홈런, 100승, 100세이브 등)
- 특수 이력: 우승 경력, 한 시즌 특정 타이틀, 국가대표는 후속 데이터 확보 뒤 추가

구단 조건은 해태/KIA처럼 전신을 합칠지 칸마다 명시한다. 수상 조건은 올스타 추천선수와 베스트12, 정규시즌 MVP와 시리즈 MVP를 구분한다.

## 선수 덱 원칙

- 36장 기준 현역 22~24명, 은퇴 12~14명을 목표로 한다.
- 첫 8장 중 최소 5장은 인지도가 높은 현역 선수로 구성한다.
- 한 칸에만 들어가는 카드와 여러 칸에 들어가는 카드를 섞는다.
- 같은 선수·같은 조건은 최근 14일 동안 과도하게 반복하지 않는다.
- 동명이인은 선수 ID, 소속 시즌과 생년월일로 분리한다.

## 데이터 모델

전체 기록실을 복제하지 않고 날짜별 문제와 판정 집합을 저장한다.

```json
{
  "id": "kbo-bingo-2026-09-08",
  "game": "kbo-bingo",
  "publishDate": "2026-09-08",
  "revision": 1,
  "board": [
    {
      "id": "golden-glove",
      "label": "골든글러브 수상",
      "validPlayerIds": [10001, 10002]
    }
  ],
  "deck": [10001, 10017],
  "maxCards": 36,
  "sources": [],
  "review": {
    "status": "verified",
    "reviewedAt": "2026-09-07"
  }
}
```

각 칸은 화면에서 실시간 검색하지 않고, 출제 시점에 확정한 `validPlayerIds`로 판정한다. 선수명·현역 상태·표시용 팀은 공통 선수 인덱스에서 가져온다.

## 출제 검증기

공개 전 스크립트가 다음을 검사해야 한다.

- 조건 16개와 선수 카드 36개가 중복 없이 존재하는가
- 모든 조건에 덱 안의 유효 선수가 최소 2명 있는가
- 이분 매칭으로 16칸 전체를 채우는 해답이 존재하는가
- 카드 4장을 임의로 제거한 모든 경우에도 완성 가능한가
- 카드 8장을 제거하는 10,000개 표본 시나리오 중 99% 이상에서 완성 가능한가
- 첫 6장과 전체 덱의 현역 비율 규칙을 만족하는가
- 실제 정답 ID와 저장된 출처가 일치하는가

`4장 제거 전수 검사`와 `8장 제거 표본 검사`는 패스·오답이 발생해도 판 자체가 운 때문에 막히지 않게 하는 최소 기준이다. 사용자가 다목적 선수를 잘못 배치해 생기는 전략적 실패까지 자동으로 없애지는 않는다.

## 난이도 보정

16칸에 24장은 버릴 수 있는 카드가 8장뿐이라 첫 버전으로는 지나치게 가혹하다. MVP 기본 덱은 36장으로 두고, 사용자는 완성 즉시 게임을 끝내므로 덱 증가가 곧 36턴 플레이를 의미하지는 않는다.

- 목표 성공률: 65~80%
- 목표 완성 중앙값: 26~31장
- 베타 성공률이 55% 미만이면 40장, 45% 미만이면 45장으로 확대
- 성공률이 85%를 넘으면 덱을 줄이기보다 조건 중복과 다목적 선수 비율을 먼저 조정

45장은 초보자 모드 또는 친구방 옵션으로 남겨둔다.

## 화면 구조

모바일을 기준으로 선수 카드를 상단에 고정하고 그 아래 4×4 판을 둔다.

- 상단: 현재 선수 이름, 당시/현재 팀 표시, 남은 카드 수
- 중앙: 4×4 조건판. 빈칸은 조건, 성공 칸은 선수명과 초록색
- 하단: 패스 버튼과 짧은 판정 피드백
- 성공: 완성 애니메이션 뒤 결과판, 사용 카드 수, 공유 버튼
- 실패: 채우지 못한 칸과 각 칸의 대표 정답 1명 공개

오답 문구는 설명을 길게 붙이지 않고 `이 칸에는 들어가지 않습니다`까지만 표시한다. 정답 전체 목록은 게임 종료 뒤에도 노출하지 않는다.

## 출시 단계

### 1단계 — 데일리 솔로

- 수동 검수한 7개 문제로 베타 시작
- 4×4 고정, 카드 36장, 현역 중심 덱
- 로컬 진행 저장, 결과 공유, 날짜 이동

### 2단계 — 무제한

- 검증된 조건·선수 관계 풀에서 서버가 판을 생성
- 난이도와 현역/레전드 비중 선택

### 3단계 — 친구와 함께

- 같은 판과 같은 덱을 방 코드로 공유
- 각자 어느 칸에 선수를 배치하는지에 따라 결과가 갈리는 비동기 경쟁
- 실시간 방은 솔로 리텐션과 데이터 안정성이 확인된 뒤 검토

## 출시 전 결정 사항

- 선수 사진 없이 이름 카드로 시작할지
- 구단 전신을 기본 통합할지 칸별 표기만 할지
- 실패 시 대표 정답을 공개할지 조건만 남길지

권장안은 `사진 없이 시작`, `전신 여부 칸별 명시`, `실패 시 대표 정답 1명 공개`다.
