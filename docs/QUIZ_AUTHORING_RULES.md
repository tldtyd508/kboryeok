# 퀴즈 출제 규칙

## 기본 원칙

- 초기 운영 주기는 하루 한 문제다.
- 자동 생성보다 사람이 검증한 정확한 문제를 우선한다.
- 모든 문제는 정답뿐 아니라 판정 근거와 출처를 저장한다.
- 출처가 충돌하면 KBO 공식 자료를 우선하고 보조 출처의 차이를 기록한다.
- 전체 기록실을 복제하지 않고, 확정된 문제에 필요한 데이터만 출제 시점에 수집해 스냅샷으로 저장한다.
- 브라우저에서 외부 기록 사이트를 실시간 조회하지 않는다. 모든 사용자는 검수된 동일 스냅샷으로 플레이한다.

## 문제에 반드시 저장할 정보

- 문제 ID와 공개 날짜(KST)
- 게임 모드와 난이도
- 문제 제목과 지시문
- 정답 및 허용 답안
- 해설
- 기준 시즌 또는 기준일
- 기록 범위(정규시즌/포스트시즌/국가대표 포함 여부)
- 선수 범위(현역/2000년 이후/KBO 전체)
- 출처 URL과 확인일
- 출제자와 최종 검수자

## 판정 기준

### 선수와 소속

- `등록`과 `1군 출장`을 구분한다.
- 한 경기라도 출장한 경력을 인정하는지 단순 등록도 인정하는지 문제에 명시한다.
- 군·경팀, 육성선수 기간, 2군 전용 경력을 포함하는지 명시한다.
- 개명 선수와 외국인 선수의 복수 표기를 허용 답안으로 관리한다.

### 구단 계보

- 해태/KIA, 빙그레/한화, OB/두산, SK/SSG 등 명칭 변경은 문제별 기준을 명시한다.
- 삼미–청보–태평양–현대와 현대–키움처럼 법인·선수단·팬 인식이 엇갈리는 계보는 자동으로 동일 처리하지 않는다.
- 전신 구단 인정 여부를 문제 설명이나 정보 버튼에서 확인할 수 있어야 한다.

### 기록과 수상

- 기록은 정규시즌과 포스트시즌을 기본적으로 분리한다.
- 동률 순위의 처리 방식과 한 선수의 복수 시즌 포함 여부를 명시한다.
- 수상 경력은 `커리어 전체 수상`인지 `해당 구단·시즌에서의 수상`인지 구분한다.
- 집계 값은 원자료의 기준일과 함께 저장한다.

#### 크보텐 표본 기준

`1,000타석 / 1,000이닝`을 모든 역대 기록에 일괄 적용하지 않는다. 누적 기록은 기록 자체가 충분한 표본을 뜻하고, 비율 기록만 최소 표본을 적용한다.

- 통산 타자 비율 기록(타율·출루율·장타율·OPS): 기본 `3,000타석 이상`
- 통산 투수 비율 기록(평균자책점·WHIP 등): 기본 `1,000이닝 이상`
- 단일 시즌 타자 비율 기록: 해당 시즌 공식 규정타석(팀 경기 수 × 3.1)
- 단일 시즌 투수 비율 기록: 해당 시즌 공식 규정이닝(팀 경기 수 × 1.0)
- 누적 기록(안타·홈런·타점·승리·탈삼진·세이브·홀드 등): 별도 최소 타석·이닝 없음
- 수상자 명단·수상 횟수: 타석·이닝 최소 표본 없음. `award-list` 또는 `award-counting`으로 구분한다.

외국인 선수만, 불펜 투수만처럼 역할을 제한한 문제는 기본 기준을 그대로 적용하면 후보가 지나치게 줄 수 있다. 예외 기준은 후보 수 분포를 확인한 뒤 문제 제목과 `eligibility` 필드에 명시하고, 일반 통산 순위와 섞지 않는다.

#### 크보텐 주제 편성

크보텐은 통산 기록 순위만 반복하지 않는다. 최근 10개 문제 기준으로 아래 비율을 목표로 한다.

- 통산 누적·비율 기록: 최대 4문제
- 단일 시즌·특정 기간 기록: 최소 3문제
- 수상·선정·역사 명단: 최소 3문제

수상 문제는 정확히 10명의 답이 성립하는 형식을 우선한다.

- 특정 시즌 골든글러브 수상자 10명
- 최근 10시즌 KBO MVP 또는 신인상 수상자
- 최근 10시즌 한국시리즈 MVP
- 최근 10시즌 올스타 팬 투표 최다 득표자
- 역대 골든글러브·올스타 베스트 선정 횟수 TOP 10

`award-list`는 열 명을 찾는 명단형 문제이며 표시 순서는 연도·포지션처럼 문제에 명시된 기준을 따른다. `award-counting`은 수상 횟수 순위형 문제로, 기존 기록 순위와 동일하게 11위 경계와 동률을 검증한다. 올스타는 `베스트12 선정`, `감독 추천 출전`, `실제 경기 출전`을 서로 섞지 않는다. MVP는 정규시즌 MVP, 한국시리즈 MVP, 올스타전 MVP, 월간 MVP를 별도 범주로 취급한다.

### 관계형 문제

- 커넥션과 공통분모는 의도하지 않은 복수 그룹 가능성을 검수한다.
- 야구사목은 각 칸의 유효 선수 ID 목록을 출제 시점에 고정한다.
- 트레이드와 보상선수는 날짜, 상대 구단, 이동 방식과 포함 선수를 모두 기록한다.

## 출처 정책

우선순위:

1. KBO 공식 홈페이지, 공식 연감과 공시
2. 구단 공식 홈페이지와 공식 보도자료
3. 공신력 있는 기록 데이터베이스 및 언론 기사
4. 나무위키 등 보조 인덱스

나무위키는 후보 탐색과 누락 확인에 사용할 수 있지만 단독 근거로 정답을 확정하지 않는다. 사진, 영상, 응원가와 인터뷰는 사용 권리와 인용 범위를 별도로 확인한다.

출처 표기는 수집·재사용 허가를 대신하지 않는다. 크롤링 금지 또는 콘텐츠 이용 제한이 명시된 사이트는 링크를 표기하더라도 수집원으로 사용하지 않는다. STATIZ는 별도 허가가 확보되기 전까지 자동·수동 스크레이핑 대상에서 제외한다.

### 크보텐

- 정확히 10개의 서로 구분되는 정답이 있는가
- 최소 표본(타석·이닝 등), 기준일, 동률 처리 방식이 화면에 보이는가
- 현역·은퇴·해외 진출 선수를 동일한 선수 인덱스로 판정하는가
- 공개 후 기록 정정이 발생해도 당시 스냅샷과 수정 이력이 보존되는가
- 비율 기록이면 `eligibility.recordType`, 최소 타석·이닝과 규칙 출처가 저장되어 있는가
- 기본 라이프는 3개이며, 후보 선택 오류가 아닌 실제 오답만 차감되는가
- 수상 문제라면 상의 정확한 명칭, 대상 시즌, 선정 기준과 표시 순서가 명시되어 있는가
- 수상 횟수 문제라면 공동 수상·복수 포지션·올스타 추천선수 포함 여부가 명시되어 있는가

## 모드별 체크리스트

### 오늘의 크보선수

- 당일 정답이 선수 풀에 존재하는가
- 팀, 포지션, 투타, 생년월일, 등번호가 기준일에 맞는가
- 한국 시간 기준으로 모든 사용자에게 같은 문제가 노출되는가

### 크보 커넥션

- 16명이 정확히 네 그룹으로 나뉘는가
- 미끼 선수 때문에 복수의 완전한 해답이 생기지 않는가
- 각 그룹의 기준 문장이 모호하지 않은가

### 크보 5001

- 선택 가능한 조합을 전수 검사했는가
- 해답이 존재하며 지나치게 많거나 하나뿐이지 않은가
- `이상`, `이하`, `정확히`, `초과 금지`를 명확히 표시했는가

### 크보 빙고

- 조건 16개와 선수 카드 36개가 중복 없이 존재하는가
- 구단·포지션·투타·출생연도·등번호 조건은 수동 `validPlayerIds`가 아니라 `attributePlayerFacts`와 `rule`로 계산하는가
- 속성 스냅샷에서 제외한 선수는 `attributeExcludedPlayerIds`에 명시하고, 화면 조건도 `현역`·`현재`처럼 적용 범위를 밝히는가
- 수상·우승·과거 이력 칸의 `validPlayerIds`가 공식 근거와 일치하는가
- 전체 판을 채우는 이분 매칭 해답이 존재하는가
- 카드 4장 제거 전수 검사와 카드 8장 제거 10,000개 표본 검사를 통과하는가
- 덱은 현역 중심이며 초반 8장에 인지도가 높은 현역 선수가 충분한가
- 구단 전신, 수상 종류, 정규시즌과 포스트시즌 범위를 조건 문구에서 구분했는가

### 등번호 연대기

- 각 시즌의 구단과 번호를 2개 이상의 신뢰 가능한 자료로 교차검증했는가
- 미출장·프리시즌 번호를 포함했다면 별도 표기했는가

### Missing 9

- 경기 날짜, 타순, 포지션, 선발투수와 교체 여부가 정확한가
- 선발 9명과 전체 출전 선수를 혼동하지 않도록 문제 범위를 명시했는가
