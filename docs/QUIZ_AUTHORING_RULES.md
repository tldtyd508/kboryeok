# 퀴즈 출제 규칙

## 기본 원칙

- 초기 운영 주기는 하루 한 문제다.
- 자동 생성보다 사람이 검증한 정확한 문제를 우선한다.
- 모든 문제는 정답뿐 아니라 판정 근거와 출처를 저장한다.
- 출처가 충돌하면 KBO 공식 자료를 우선하고 보조 출처의 차이를 기록한다.

## 문제에 반드시 저장할 정보

- 문제 ID와 공개 날짜(KST)
- 게임 모드와 난이도
- 문제 제목과 지시문
- 정답 및 허용 답안
- 해설
- 기준 시즌 또는 기준일
- 기록 범위(정규시즌/포스트시즌/국가대표 포함 여부)
- 선수 범위(현역/2000년 이후/KBO 전체)
- 출처 URL과 확인일
- 출제자와 최종 검수자

## 판정 기준

### 선수와 소속

- `등록`과 `1군 출장`을 구분한다.
- 한 경기라도 출장한 경력을 인정하는지 단순 등록도 인정하는지 문제에 명시한다.
- 군·경팀, 육성선수 기간, 2군 전용 경력을 포함하는지 명시한다.
- 개명 선수와 외국인 선수의 복수 표기를 허용 답안으로 관리한다.

### 구단 계보

- 해태/KIA, 빙그레/한화, OB/두산, SK/SSG 등 명칭 변경은 문제별 기준을 명시한다.
- 삼미–청보–태평양–현대와 현대–키움처럼 법인·선수단·팬 인식이 엇갈리는 계보는 자동으로 동일 처리하지 않는다.
- 전신 구단 인정 여부를 문제 설명이나 정보 버튼에서 확인할 수 있어야 한다.

### 기록과 수상

- 기록은 정규시즌과 포스트시즌을 기본적으로 분리한다.
- 동률 순위의 처리 방식과 한 선수의 복수 시즌 포함 여부를 명시한다.
- 수상 경력은 `커리어 전체 수상`인지 `해당 구단·시즌에서의 수상`인지 구분한다.
- 집계 값은 원자료의 기준일과 함께 저장한다.

### 관계형 문제

- 커넥션과 공통분모는 의도하지 않은 복수 그룹 가능성을 검수한다.
- 야구사목은 각 칸의 유효 선수 ID 목록을 출제 시점에 고정한다.
- 트레이드와 보상선수는 날짜, 상대 구단, 이동 방식과 포함 선수를 모두 기록한다.

## 출처 정책

우선순위:

1. KBO 공식 홈페이지, 공식 연감과 공시
2. 구단 공식 홈페이지와 공식 보도자료
3. 공신력 있는 기록 데이터베이스 및 언론 기사
4. 나무위키 등 보조 인덱스

나무위키는 후보 탐색과 누락 확인에 사용할 수 있지만 단독 근거로 정답을 확정하지 않는다. 사진, 영상, 응원가와 인터뷰는 사용 권리와 인용 범위를 별도로 확인한다.

## 모드별 체크리스트

### 오늘의 크보선수

- 당일 정답이 선수 풀에 존재하는가
- 팀, 포지션, 투타, 생년월일, 등번호가 기준일에 맞는가
- 한국 시간 기준으로 모든 사용자에게 같은 문제가 노출되는가

### 크보 커넥션

- 16명이 정확히 네 그룹으로 나뉘는가
- 미끼 선수 때문에 복수의 완전한 해답이 생기지 않는가
- 각 그룹의 기준 문장이 모호하지 않은가

### 크보 5001

- 선택 가능한 조합을 전수 검사했는가
- 해답이 존재하며 지나치게 많거나 하나뿐이지 않은가
- `이상`, `이하`, `정확히`, `초과 금지`를 명확히 표시했는가

### 등번호 연대기

- 각 시즌의 구단과 번호를 2개 이상의 신뢰 가능한 자료로 교차검증했는가
- 미출장·프리시즌 번호를 포함했다면 별도 표기했는가

### Missing 9

- 경기 날짜, 타순, 포지션, 선발투수와 교체 여부가 정확한가
- 선발 9명과 전체 출전 선수를 혼동하지 않도록 문제 범위를 명시했는가

## 공개 전 최종 검수

- [ ] 모바일과 데스크톱에서 문제를 끝까지 풀었다.
- [ ] 정답·오답·재시도·공유 상태를 확인했다.
- [ ] 맞춤법과 선수 이름 표기를 확인했다.
- [ ] 모든 출처 링크가 열리고 근거를 직접 뒷받침한다.
- [ ] 다음 날 문제로 전환되는 KST 경계를 확인했다.
