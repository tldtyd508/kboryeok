# 크보력 제품 비전

## 한 문장 정의

크보력은 KBO 선수를 재료로 추리, 기록, 관계, 역사, 전략을 매일 다르게 즐기는 야구 퀴즈 플랫폼이다.

## 우리가 만들려는 경험

- 단순 암기보다 팬이 쌓아온 야구 감각을 시험한다.
- 라이트 팬은 현역 선수부터 시작하고 올드 팬은 KBO 전체 역사까지 도전한다.
- 각 게임은 3~5분 안에 끝나지만 결과를 공유하고 다른 팬과 이야기할 이유를 만든다.
- 하루 한 문제를 기본으로 하되 지난 문제를 즐길 수 있는 아카이브를 장기적으로 제공한다.
- 게임을 플레이할수록 검증된 KBO 데이터와 명경기 콘텐츠가 제품 자산으로 축적된다.

## 게임별 역할

| 역할 | 게임 |
| --- | --- |
| 가장 쉬운 입구 | 오늘의 크보선수 |
| 서비스 간판 | 크보 커넥션 |
| 독자적 시그니처 | 크보 5001 |
| 시각적 홍보 콘텐츠 | 등번호 연대기 |
| 기록 덕후용 | 크보텐 |
| KBO 역사 아카이브 | Missing 9 |
| 반복 플레이·대결 | 야구사목 |
| 제도·이적 특화 | 보상선수 추리, 트레이드 족보 |
| 라이트 유저 유입 | 더 높냐 낮냐 |
| 커뮤니티 활성화 | 크보병 |
| 미래형 플래그십 | 크보텍스 |

## 초기 출시 라인업

1. **오늘의 크보선수**: 팀, 포지션, 투타, 나이, 등번호로 선수를 추리한다.
2. **크보 커넥션**: 16명의 선수를 네 개의 공통점으로 묶는다.
3. **크보 5001**: 제한된 선수 카드의 누적 기록을 조합해 목표 수치를 만든다.
4. **등번호 연대기**: 한 선수의 등번호 변화를 보고 정답을 추리하는 주간 스페셜이다.

## 제품 원칙

1. **KBO다워야 한다.** 다른 스포츠 이름만 바꾼 복제품보다 구단 계보, 보상선수, 등번호, 명경기처럼 KBO 문화가 드러나는 소재를 우선한다.
2. **판정은 설명 가능해야 한다.** 기준 시즌, 기록 범위, 구단 계보와 수상 기준을 문제마다 명시한다.
3. **수동 운영부터 시작한다.** 하루 한 문제를 직접 출제·검수하고, 반복되는 작업이 확인된 뒤 자동화한다.
4. **한 데이터로 여러 재미를 만든다.** 선수 기본 정보와 시즌·통산 기록을 여러 게임이 함께 사용한다.
5. **결과가 콘텐츠여야 한다.** 이모지나 짧은 점수표만으로도 플레이 결과가 이해되고 공유되어야 한다.

## 성공 신호

- 오늘의 문제를 다시 풀기 위해 재방문한다.
- 결과 공유만 보고도 어떤 게임인지 궁금해진다.
- 정답과 기준에 관한 팬 토론이 건설적으로 발생한다.
- 수동 출제 시간이 한 문제당 10~30분 안으로 안정된다.
- 축적된 문제와 출처가 재사용 가능한 KBO 아카이브가 된다.

## 참고
