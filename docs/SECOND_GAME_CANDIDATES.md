# 두 번째 게임 후보 검토

두 번째 게임은 `오늘의 크보선수`와 플레이 감각이 달라야 하며, 결과 공유와 반복 방문을 강화해야 한다. 아직 후보를 확정하지 않고 아래 세 방향을 우선 검토한다.

## A. 크보 커넥션

- 형식: 16명의 선수를 네 공통점으로 분류
- 장점: 한 화면만으로 규칙이 전달되고 공유 결과가 선명하다. 선수 관계와 KBO 문화가 잘 드러난다.
- 위험: 복수 정답과 조건 중첩을 매번 검수해야 한다. 데일리 운영 부담이 가장 크다.
- 현실적인 출시안: 주 2회 수동 출제 베타
- 적합한 목표: 크보력만의 대표 게임 확보

## B. 진짜 기록은 어느 쪽?

- 형식: 실제 기록과 그럴듯한 가짜 기록 중 하나를 선택하는 5라운드 퀴즈
- 장점: 모바일에서 빠르고, `4/5`처럼 공유하기 쉽다. 작은 검수 데이터만으로 출시할 수 있다.
- 위험: 객관식이라 장기적으로 패턴이 단순해질 수 있다. 정확한 출처 관리가 필수다.
- 현실적인 출시안: 매일 5문항 또는 주 3세트
- 적합한 목표: 가장 빠르게 두 번째 데일리 게임 오픈

## C. 더 높냐 낮냐

- 형식: 두 선수 중 특정 시즌·통산 기록이 높은 쪽을 연속 선택
- 장점: 무제한 플레이와 최고 연속 기록에 적합하다. 문제를 수동으로 매일 만들 필요가 적다.
- 위험: 현재 등록 선수 XLSX만으로는 부족하며 시즌별 타격·투구 기록 데이터가 필요하다.
- 현실적인 출시안: 기록 데이터 파이프라인 구축 후 무제한 모드
- 적합한 목표: 체류 시간과 반복 플레이 확대

## 후순위 후보

- `Missing 9`: 팬 매력은 높지만 과거 경기 라인업 확보와 검수 비용이 큼
- `커리어 패스`: 선수 이동 이력 데이터 정규화가 선행되어야 함
- `등번호 연대기`: 차별성은 높지만 시즌별 등번호 이력이 필요함

## 결정 질문

1. 두 번째 게임의 최우선 목표가 빠른 출시인가, 대표 게임 확보인가?
2. 초기에는 데일리 대신 주 2~3회 공개도 허용할 것인가?
3. 수동 출제에 주당 어느 정도 시간을 사용할 수 있는가?

현재 판단:

- 빠른 출시 우선: `진짜 기록은 어느 쪽?`
- 브랜드와 차별성 우선: `크보 커넥션`
- 장기 자동화와 체류 시간 우선: `더 높냐 낮냐`
