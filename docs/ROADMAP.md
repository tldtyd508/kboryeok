# 크보력 로드맵

## 현재 상태

- `오늘의 크보선수` 플레이 가능
- `크보텐` 베타 플레이 가능
- `크보 5001` 플레이 가능
- `크보 빙고` 데일리 베타 플레이 가능
- KBO 공식 등록 선수 XLSX 기반 선수 데이터 파이프라인 구축
- 월 1회 데이터 최신성 검수 워크플로 구축
- Vercel 프로덕션 배포 완료

## Phase 1 — 게임 허브와 기록 기반 게임

목표: 현재 데이터 구조를 최대한 재사용해 여러 게임이 있는 서비스의 형태를 만든다.

- [x] 홈을 게임 허브로 개편
- [x] 오늘의 크보선수를 첫 번째 게임으로 배치
- [x] 게임별 라우팅
- [x] 날짜별 플레이 상태 복구와 서비스 공통 스트릭
- [x] 게임 URL을 포함한 네이티브 공유·복사 UI
- [ ] 여러 게임에서 재사용할 공통 결과 공유 컴포넌트
- [x] [두 번째 게임 후보 확정](./SECOND_GAME_CANDIDATES.md): 크보텐
- [ ] 크보 커넥션 MVP
- [x] 크보 5001 MVP
- [x] 크보텐 베타
- [ ] 크보텐 수상·시즌·역사 주제 로테이션
- [x] 크보 빙고 데일리 MVP
- [ ] 더 높냐 낮냐
- [ ] 기록 프로필 맞히기
- [ ] 순위 배열하기

필요 데이터(전체 기록 적재가 아닌 문제별 스냅샷):

- `players`
- 현역·은퇴 통합 선수 인덱스
- 문제별 최소 기록 값과 출처 이력
- `daily_quizzes`
- `daily_quiz_options`

## Phase 2 — 수동 출제 시스템

목표: 운영자가 코드나 원본 JSON을 직접 수정하지 않고 하루 한 문제를 10분 안에 등록한다.

- [ ] 문제 제목, 설명, 날짜, 난이도 입력
- [ ] 선수 카드 검색과 선택
- [ ] 정답·그룹·순서 편집
- [ ] 해설과 출처 URL 저장
- [ ] 미리보기 및 예약 공개
- [ ] 중복 조건과 복수 정답 검수

이 단계에서 추가할 게임:

- 크보 커넥션 정식판
- 진짜 기록 찾기
- 크보 타임라인
- 공통분모
- 등번호 연대기
- Missing 9
- 보상선수 추리
- 트레이드 족보

## Phase 3 — 선수 관계 데이터

목표: 모든 입력을 실시간 판정할 수 있는 관계 그래프를 구축한다.

- `player_team_history`
- `player_awards`
- `player_numbers`
- `player_positions`
- `player_transactions`
- `player_relationship_tags`

이후 출시 후보:

- 후보 선택형 야구사목 → 자유입력형 야구사목
- 고정 카드덱 크보 빙고
- 선수 연결고리
- 중복 답 금지형 크보병
- 샐러리캡·블라인드 드래프트

## Phase 4 — 커뮤니티와 미래형 게임

- 실제 응답률 기반 희귀도 점수
- PvP 야구사목과 구단 영토전
- 유저 문제 제보 및 검수 흐름
- 선수 관계 그래프 기반 크보텍스
- 무제한 아카이브와 개인 기록

## 우선순위 기준

새 게임은 다음 항목을 각각 평가한다.

1. KBO 역사·문화·팬심을 드러내는가
2. 다른 스포츠에 그대로 복사하기 어려운가
3. 한 화면과 제목만으로 기억되는가
4. 결과 공유가 재미있는가
5. 초기 데이터 확보와 일일 검수 비용이 감당 가능한가
6. 기존 데이터와 UI를 재사용할 수 있는가

현재 종합 우선순위는 다음과 같다.

`크보 빙고 → 크보 커넥션 → 등번호 연대기 → Missing 9 → 후보형 야구사목`
